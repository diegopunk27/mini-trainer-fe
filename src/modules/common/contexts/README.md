## Uso

Contiene los archivos de gestión de contextos.

- Cada contexto empleado deberá tener su propio subdirectorio en que se contendrán los archivos `.provider.tsx` y `.context.tsx` como así también un `index.ts` que exporte ambos componentes.

  - `context` contendrá el `createContext()`;
  - `provider` contendrá todos los métodos del contexto.
