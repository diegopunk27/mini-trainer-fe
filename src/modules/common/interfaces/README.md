## Uso

Contiene las interfaces ncesarias a lo largo de toda la aplicación.

- Se divide en dos carpetas:

  - api: para todas aquellas interfaces relacionadas con requests y responses a APIs como así también cualquier interfaz necesaria para los servicios API; y
  - local: para todas aquellas interfaces internas de la app.

- Los archivos contenidos acá deben llevar la type extensión `.interface`.
